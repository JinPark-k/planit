# core/

배포 방식과 무관한 순수 도메인 로직만 위치한다.

- `@nestjs/*`, `express`, `../../adapters/*` 를 import 하지 않는다.
- Nest를 부팅하지 않고도 유닛테스트 가능해야 한다.
- `batch/`에서도 (Nest DI 없이) 그대로 재사용 가능해야 한다.
- LLM을 사용하지 않는다. 규칙 기반 로직만 작성한다 (비용 예측 가능성 때문).

인프라 전환(Vercel → Oracle/AWS 등) 시 이 폴더는 절대 수정하지 않는다. 변경은 `adapters/`에서만 일어난다.
